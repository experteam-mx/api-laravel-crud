# Changelog

Notable changes to this package. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/).

## [3.6.1] - 2026-11-24

### Changed
- Accepts `experteam/api-laravel-base` 3.x as well as 2.x. The code is the same as 3.6.0.

### Notes
- Bridge release for APIs that stay on the 3.6 line and need `experteam/api-laravel-base` 3.x. The 3.7 line adds audit records for deleted models and still requires base 2.x. 4.0.0 has the 3.7.5 code and requires base 3.x.

## [3.6.0] - 2025-11-18

### Added
- Laravel 12 support.
